# DMC5 font

`dmc5.ttf` — "Dmc5 Font By Kalina Ann", downloaded 2026-10-10 from
https://hyperpix.net/fonts/devil-may-cry-font/
(archive `devil-may-cry.zip`, file `Devil May Cry.ttf`).

License stated by the source: free for **personal projects**. Check with the
author before any commercial or public use.

The font has only lowercase a–z and the space. The dashboard uses it for the
"VIGIL AI" wordmark next to the logo, lowercased by CSS once the font has
loaded (see `dashboard/css/vigil-shell.css` and `dashboard/js/vigil-theme.js`).
